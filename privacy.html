Privacy Policy

This page describes the behavior of the current static MapleToolbox website. The site owner should review it against the actual hosting and operational setup before launch.

Calculator entries

Calculator inputs are processed in the browser by the site’s JavaScript. The current project has no application backend or first-party analytics integration, and the calculation code does not transmit the values entered into calculator fields.

Browser storage

The site stores a light/dark theme preference in your browser’s local storage. Calculator values are not stored by the site after you leave or reload a page.

Hosting and external links

When the site is deployed, its hosting provider may process standard request information such as IP address, user-agent, and requested URL in server logs. The site owner should add the selected provider’s logging, retention, and contact details here. Links to official sources and other external websites are subject to those sites’ own privacy practices.

Questions

Before publishing, provide a monitored contact address on the Contact page for privacy inquiries.
